 Summarization and Contextualization (The "LLM Logic" Team)
Goal: Explore how to verify if an AI answer matches the source material.
Preliminary Study Brief:
Objective: Analyze techniques for evaluating the "faithfulness" and "relevance" of Large Language Model (LLM) outputs against a source document.

Tasks for Preliminary Analysis:
1.	Metric Survey: Research existing evaluation metrics for RAG (Retrieval-Augmented Generation) systems (e.g., ROUGE, BLEU, BERTScore, Faithfulness scores).
2.	Case Study: Take a short regulatory text and generate 3 different AI answers (one perfect, one partially correct, one hallucinated).
3.	Evaluation: Try to manually and automatically score these answers. What metrics fail to catch the hallucination?
4.	Context Window: Investigate how much context an LLM can handle before it starts "forgetting" or hallucinating.
5.	Deliverable: A 2-page report titled "Limitations of Current LLM Evaluation Metrics in High-Stakes Domains" with a comparison table of tools.
Key Question  "Can current automated metrics reliably distinguish between a 'correct' answer and a 'plausible but wrong' answer
